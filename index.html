Connect to your Frame

Find your TV’s IP address

  1. Turn on your TV. Keep it and this computer connected to the same home network.
  2. On the TV remote, open Settings → All Settings → Connection → Network → Network Status → IP Settings. Find the number labeled IP Address. On older TVs, try Settings → General → Network → Network Status → IP Settings.
  3. Type that number in Stillroom’s TV address box. Use the numbers and dots only, then select Pair TV.
  4. Look at the TV and accept the Stillroom connection request. Once paired, choose a work and select Send to Frame TV.

If pairing fails, check that the address belongs to the TV, the TV is awake, and neither device is on an isolated guest network. Menus can vary by model. Samsung’s network guide ↗
Direct transfer depends on the TV’s Art Mode support. You can always download the JPEG and add it with SmartThings or USB.
